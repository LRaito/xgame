# XGAME

个人自托管的**游戏平台**：把 Flash、HTML5 与 8/16-bit 主机游戏收进一个网页，浏览器打开就能玩，
存档、截图、攻略与游玩进度都跟着账号走。

> 这是**使用指南**：怎么装起来、怎么玩。要改代码、看架构与数据字典，见 [`DEVELOP.md`](DEVELOP.md)。

## 两种装法，选一种

|  | Windows 解压即用包 | Linux 部署（Docker） |
| --- | --- | --- |
| **适合谁** | 家里一台 Windows，自己或家人用；不想碰命令行 | 一台常开的 Linux / WSL 机器，想要 HTTPS |
| **怎么装** | 下载 `xgame_v*.zip` → 解压 → 双击「启动游戏平台.cmd」 | `git clone` → `make all` |
| **怎么打开** | 浏览器自动打开 `http://127.0.0.1:8910` | 浏览器打开 `https://localhost` |
| **手机 / 平板** | 能（同一个 Wi-Fi 下） | 能（用局域网 IP 访问） |
| **怎么升级** | 关掉窗口 → 解压新包到新目录 → 把 `data` 搬过去 | `git pull` + `make all` |
| **数据在哪** | 包里的 `data` 文件夹 | 你在 `.env` 里配的那个目录 |

两种装法的**数据格式完全一样**，同一份数据目录可以换着用。但**不要同时开着同一份数据目录**，
会把数据库写坏——换过去之前先把另一边停掉。

## 快速开始

### Windows 游玩

先拿到 `xgame_v*.zip`：找发给你的人要一份，或者自己在这台机器上打一份
（`make win`，见 [`DEVELOP.md`](DEVELOP.md)）。

1. **先解除锁定，再解压**：右键 zip → 属性 → 勾选「解除锁定」→ 确定。这一步只做一次，
   但建议别跳过——不勾的话，解压出来的文件都带着「来自 Internet」标记，以后每双击一次
   `.bat`/`.cmd`，Windows 都会先弹一次「无法验证发布者」（点「运行」也能继续，只是每次都要点）。
2. 把 zip 解压到一个新文件夹里（压缩包里没有多余的一层目录，解压出来就是包本体）。
   **路径别太深、别太长**（Windows 对路径长度有上限）。已经解压了才看到这条的，
   双击一次包里的「解除锁定.bat」补上即可。
3. 双击「启动游戏平台.cmd」。首次启动要准备数据，可能要十几秒，属正常。
4. 浏览器会自动打开。看到登录页就成了，点「注册一个」建个账号就能玩。

那个黑色窗口就是服务本身：**关掉窗口 = 停止服务**，想一直开着就把它最小化。

**想让手机、平板也能玩**：双击一次「允许局域网访问.bat」（会弹一次权限确认，点「是」），
然后用启动窗口里打印的那个「局域网内（手机/平板）」地址。

平时需要知道的就三件事：

- **数据**全在 `data` 文件夹里（账号、存档、截图、游戏本体），**拷走它就是完整备份**。
- **升级**：关掉窗口 → 把新 zip 解压到一个**新文件夹** → 把旧文件夹里的 `data` 搬过去 →
  双击新的「启动游戏平台.cmd」。账号、存档、截图、游戏都在 `data` 里，跟着搬就都在。
- **卸载**：删掉整个文件夹。数据也在里面，删了就一起没了。

包里的「说明.txt」写得更细（连不上、被系统拦、端口被占用之类）；打包方式见 [`DEVELOP.md`](DEVELOP.md)。

### Linux 部署（Docker）

1. 建配置文件，填数据放哪：

```bash
cp .env.example .env
# 编辑 .env：STORAGE_HOST_DIR=/srv/xgame/storage    ← 游戏、存档、截图、备份都放这儿
#           RUNTIME_HOST_DIR=/srv/xgame/runtime    ← 数据库单独放这儿（默认 ./data/runtime）
```

**想用网盘（或任何外部工具）备份数据目录，就让运行时目录待在网盘之外**：

```bash
STORAGE_HOST_DIR=/srv/xgame/storage        # ← 这份要备份
RUNTIME_HOST_DIR=/home/you/xgame-runtime   # 只有数据库，放在网盘之外 ← 这份不用备份
```

`RUNTIME_HOST_DIR` 留空就退回与 `STORAGE_HOST_DIR` 相同（库跟数据放一起，等于不分开）。库文件一直被
服务写着，网盘客户端**拷不动**它、备份任务会报「文件被占用」；把库单独放到网盘之外，数据目录里就只剩
能随便拷的普通文件（游戏、存档、截图），整个拷走就是完整备份。数据库另有兜底：服务每月留一份
`<年>-<月>.db` 在数据目录的 `db/` 里，**每小时刷新一次**，所以那份快照最多落后一小时。

2. 构建并启动（首次要联网，会去拉引擎资产）：

```bash
make all
```

3. 浏览器打开 **https://localhost**（`https://127.0.0.1` 是同一个站点）。
   证书是自签的，浏览器会警告一次，处理办法见「常见问题」。

两个容易踩的点：

- 数据目录（以及单独指定的运行时目录）要在 **Docker 启动之前就可达**，别指到会被 `git pull`
  覆盖的仓库目录里。
- 目录放在 WSL 挂进来的 Windows 盘上时（`/mnt/x/…` 这种），要在里面**手工建一个空的
  `.mounted` 文件**（只建一次），否则服务起不来。两个目录都在 Windows 盘上就是**两个文件**，
  各建在自己的目录里：

```bash
touch /mnt/x/xgame/storage/.mounted      # 数据目录
touch /mnt/x/xgame/runtime/.mounted      # 运行时目录（没单独指定就与上面是同一个文件）
```

「游戏发现」页第一次用时服务会自己把索引建好，不用管；榜单 CSV 放进
`backend/search/ranking/ranking.csv` 后重启一次也会自动加载。细节见 [`DEVELOP.md`](DEVELOP.md)。

### 注册账号

两种装法都一样：打开站点，在登录框下方点「注册一个」，填用户名（数字、字母、中划线、下划线，
2–32 个字符）和密码，**注册成功即登录**。

没有游客模式，除了注册和登录都要登录。账号只用来隔离每个人的**存档、截图、键位与进度**，
不涉及任何权限。连续输错密码会被临时锁定，等几分钟再试。

## 界面怎么用

首页就是**游戏中心**（`/` 会自动跳到 `/games`）。左侧栏有「游戏中心」「游戏管理」「游戏发现」三项。

侧栏和播放页的标题栏平时都是**收起的**：鼠标移到屏幕左边缘滑出侧栏，移到页面顶部滑出播放页标题栏
（全屏时也一样）。它们盖在页面上，不占地方、也不挤小游戏画面。

## 游戏中心

站点首页就是游戏中心。

- **找游戏** — 工具条上可以按「进度」「类型」筛选，也能按名称搜索。「全部游戏」先按游戏类型分组，
  组内再按封面类型（DISK / GB / GBC / GBA / FC / NES）分块，还没定过封面类型的自成一组排在最后；
  上面还有一行「最近游玩」。
- **卡片上有什么** — 封面、名称，以及一行进度标签 + 总游玩时长（进度还是「未开始」时这一行不显示内容，
  但仍占住位置，好让同排卡片的标题始终对齐）。
- **点一下卡片**就开始玩。
- **在卡片上点右键**（卡片以外还是浏览器原生菜单）：

| 菜单项 | 作用 |
| --- | --- |
| 详情 | 打开详情弹框（图、简介、图集与截图） |
| 攻略 | 在新标签页打开这盘游戏的攻略（没有攻略就不显示这一项） |
| 设置进度 | 未开始 / 进行中 / 已通关 |
| 设置时长 | 手动改总游玩时长（小时），之后从该数值继续累加 |

进度**不会**因为玩过就自动变，只能手动改；时长则在游玩时自动累加。

## 玩游戏

三种游戏都是点开即玩、不装插件：**Flash**（`.swf`）、**HTML5**（`.zip`，浏览器里当网页游戏跑）、
**主机**（NES / SNES / GB / GBC / GBA / MD / GG / SMS，浏览器里跑模拟器，不需要外网）。

### 播放页

标题栏右侧是「全屏」和「返回游戏中心」；左侧按钮自左向右是「加速模式」「截图」「保存配置」
「窗口倍率」「显示机壳」（只有 GBA / FC / GBC 有）、「存档管理」。

- **加速模式** — 点一下一直加速（快进 3×），再点恢复。它开关的就是模拟器自己的
  「Fast Forward」设置，所以下次进这个平台的游戏会直接是加速状态，点「保存配置」还会跟着
  同步到账号；引擎里自己绑的快进键照旧能用（按住加速、松手恢复）。
- **保存配置** — 键位、模拟器选项、金手指按平台存在账号里，进游戏时会自动写回；**改完记得点它上传**。
- **窗口倍率** — 弹出两列矩阵：行是 `1×`–`4×`（含 .5 档）与「适应窗口」，列是显示比例。
  默认「像素完美」；FC 还多一列「4:3」，是真机 CRT 的观感。
- **显示机壳** — 把 GBA / FC / GBC 的机身图盖在画面上，只从屏幕洞里露出游戏画面；再点一次收起。
- **存档管理** — 见「存档」。

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Shift+S` | 截图（与标题栏的「截图」按钮同效） |
| `回车` | 载入本地存档（没有本地存档时，这一下照常交给游戏，等于主机的 Start 键） |
| `·`（数字 1 左边那个键） | 立刻把当前进度同步到云端：先捕捉、再上传，完成后提示「已同步至云端」。**Flash 会先弹确认框**——它的落盘要先重启游戏；HTML5 没有云存档，按了只会提示一句 |

`·` 这个快捷键只在玩主机（模拟器）与 Flash 时好用；HTML5 的游戏画面在沙箱里，焦点在游戏里时
按不到（点一下标题栏再按才会弹提示）。

## 存档

**本地存档**存在这台机器的浏览器里，「存档管理」里可以捕捉当前进度、导入本地文件、下载到磁盘、删除。

- **主机（模拟器）** — 每盘游戏只有一份本地档，就是「即时存档」；捕捉、导入、云端还原都是**覆盖**它。
- **Flash** — 就是 `.sol` 存档文件，可以有好几份。**得先在游戏里存过档**才能捕捉到；
  捕捉之后游戏会重启，属正常现象（原因见「常见问题」）。
- **HTML5 没有存档**（沙箱里拿不到浏览器存储）；**大部分 Flash 游戏也没有落盘存档**，进度只在内存里。
- 本地档只在这台浏览器里：换设备、换浏览器、清了站点数据都会没有。

**云端存档**跟着账号走：在「存档管理」里把**此刻的全部本地存档**整包存成一份快照传到服务器，
换设备、换浏览器、清了缓存都能还原。列表里每份快照都能载入、改名、删除。

> 在游戏管理页删掉一盘游戏时，它在**所有账号**上的云端存档与截图都会被一起删掉。

## 截图（主机游戏）

按 `Ctrl+Shift+S` 或点标题栏的「截图」，会截下当前画面并弹出确认框：左边是预览，右边可以填一句
描述（≤15 字），点「确认」才存进**你自己的**截图图库。

看和管理截图有两个入口：

- **详情弹框顶部的图片栏** — 一行 4 个格子，第一格永远是封面，后面依次是这盘游戏的**图集**和
  **你自己的截图**，格子下方显示描述。按钮和鼠标滚轮都能左右翻页。
- **详情弹框右栏的「截图 [管理]」** — 相册式平铺的管理页：可以上传本地图片、单击描述就地修改
  （回车保存、`ESC` 放弃）、按住整块拖动排序、点右上角「删除」进多选删除。

截图按账号隔离，只有本人看得到、改得动；封面是大家共享的。

## 图集

图集是**一个游戏一套的展示图**（宣传图、说明书扫描件之类），和截图正好相反：**按游戏共享**，
不记是谁传的，谁都能看、能传、能改描述、能删、能排序。

- **在哪看** — 详情弹框顶部的图片栏，排在封面之后、你的截图之前。
- **在哪管** — 游戏管理页点「编辑」，弹框里的「图集 → 管理」（新建游戏的弹框里没有这一项）。

## 攻略

攻略是**整份文件夹**上传的静态网页，入口固定是文件夹根目录的 `index.html`。有攻略的游戏，
卡片右键菜单里会多一项「攻略」，点开在新标签页里打开——攻略里的子页面、图片、CSS 都能正常互相跳转。

## 游戏管理

「游戏管理」页负责把游戏搬进来，以及改元数据。

每盘游戏有一个**卡带 ID**：添加时必填、全局唯一，同时也是磁盘上的目录名。

编辑弹框里卡带 ID 右边有一个**「修改 ID」**：点一下就地输入新的 ID，回车或「确认」提交、ESC 或「取消」放弃。
改 ID 会把磁盘上的游戏目录、以及每个账号在这盘游戏上的**云端存档与截图目录**一起改名，
所以保存即生效、不等「保存」按钮。播放页链接（按数据库 id 走）不受影响；
游戏榜单里靠旧 ID 关联的那一行会脱钩（榜单是外部数据，不会跟着改）。

### 添加游戏

| 方式 | 说明 |
| --- | --- |
| 本地上传 | 选本体文件（可同时选封面）。**游戏类型按文件后缀自动判定**，不用手选 |
| 网络上传 | 填 http/https 直链，服务端下载后入库（上限 512MB） |
| 搬运 | 填 7k7k / 4399 / flash.homes 的游戏页地址，服务端解析并下载（只支持 Flash） |

本体支持的后缀：

| 后缀 | 游戏类型 |
| --- | --- |
| `.swf` | Flash |
| `.zip` | HTML5（压缩包根目录要有 `index.html`） |
| `.nes` / `.sfc` `.smc` | FC / SNES |
| `.gb` `.gbc` / `.gba` | GB / GBA |
| `.md` `.gen` / `.gg` / `.sms` | MD / GG / SMS |

### 元数据

- **封面类型** — 这盘封面被美化成了哪种外观（DISK / GB / GBC / GBA / FC / NES）。
  新建的游戏一律是空的（显示「—」），在**编辑弹框**里用单选随时改，或者用下面的「美化封面」——
  美化时选的那种外观会自动记进来。
- **封面** — 可以单独上传或换掉。这盘游戏**已经有封面**时，旁边还能点「**美化封面**」：
  把当前封面合成成卡带（或 Flash 光盘）的外观，确认后直接换掉原封面（**不可逆**）。
  同一类型有几种外观时，弹框标题右边可以切换（`gb` 是「GB / GBC」两种，
  `nes` 是「FC / NES」两种，默认按这盘游戏当前的封面类型选）；
  合成用不上的类型（HTML5、SFC 等）不显示这个按钮。
- **名称** — 同一游戏类型下不能重名。
- **换本体** — 换了本体就跟着换游戏类型（如 `.swf` 换成 `.nes`）。第一次上传后会记住本体，
  之后换本体只接受同一个文件，防止误覆盖。
- **攻略** — 在编辑弹框里「上传攻略」选一个文件夹整体上传（重传即整体替换）。

列表按**更新时间从新到旧**排（刚传上来、刚改过的排最前），每页 5 行。
列表里每行有**详情**、**编辑**、**删除**。

**删除**会连磁盘上的游戏文件、以及**所有账号**在这盘游戏上的云端存档和截图一起清掉，
所以要**手打一遍卡带 ID** 才能确认。删之前想清楚。

## 游戏发现

「游戏发现」页有两个标签：**游戏检索**与**游戏榜单**，都只读。查的都是**平台外的数据**——和你自己
收录的游戏**是两回事**。

### 游戏检索

查一份中英文游戏名录（5 万余条、36 个机种），只用来查名字：某款游戏的中文名 / 英文名怎么叫、
某个机种上有哪些作品。

- 搜索框支持**中文名或英文名**：中文搜子串（搜「马里奥」能搜到「超级马里奥兄弟」，单个汉字也行），
  英文按整词匹配、不区分大小写，词尾加 `*` 是前缀匹配（如 `mario*`）。多个词用空格隔开。
- **机种**下拉可以只看某个机种，不选就是全部。
- 结果按相关度排序、每页 20 条。

### 游戏榜单

按机种看热门游戏排名：一个机种下拉框（默认 GBA）+ 一张极简榜单，一行是**排名、游戏名称、
0~2 个卡带 ID**（查不到编号的就是空的，显示 `—`）。**单击卡带 ID 就复制到剪贴板**，方便直接拿去搜或建条目。

榜单数据来自 `backend/search/ranking/ranking.csv`（四列：`序号,机种名称,游戏名称,游戏卡带ID`，
格式见该目录的 `README.md`）。放好文件后跑一次 `make index`，或者重启一次服务（启动时会自动加载）。

## 常见问题

### Windows 包

**双击「启动游戏平台.cmd」没反应？** 文件是从网上下载的，Windows 会拦一下。右键压缩包 →
属性 → 勾选「解除锁定」→ 重新解压；或者解压后双击一次「解除锁定.bat」。

**手机连不上？** 依次检查：手机和电脑是不是同一个 Wi-Fi；电脑上那个黑窗口是不是还开着；
有没有双击过「允许局域网访问.bat」。

**提示端口被占用？** 启动时会给明确提示。关掉占用它的程序，或者用记事本改 `xgame.ini` 里的
`port`——但**换端口等于换了站点**，浏览器里存的本地存档不会跟着走，能不改就别改。

**登录后被弹回登录页、来回跳？** 多半是同时开着两个不同地址的页面（比如一个 `127.0.0.1`、
一个局域网 IP）。同一个账号在不同地址下算两个站点，固定用一个地址就好。

**想知道到底出了什么问题？** 看 `data\logs\xgame.log`；启动失败时还会留下 `runtime\last-error.txt`。

### Docker

**浏览器说证书不安全？** 自签名证书的正常现象，三种应对：

- 点「高级 → 继续访问」—— 最省事，但换个浏览器、清了站点数据就得再来一遍。
- **把证书导入本机** —— 拿到 `certs/cert.pem`，在浏览器的证书管理里导入到「受信任的根证书颁发
  机构」，之后就是绿锁、不再报警。
- 换一张受信任的证书（见 [`DEVELOP.md`](DEVELOP.md)）。

**页面打不开、一直转圈？** 确认地址是 `https://` 开头（不支持 HTTP，也没开 80 端口），端口对不对。

**api 容器一直在重启？** 多数是数据目录的问题（不在、不可写、或 `/mnt` 盘没挂上），
见 [`DEVELOP.md`](DEVELOP.md) 的「排障」。

### 玩的时候

**存档存不上、或者存档丢了？** 先看你要存的是哪一种——这个站上一共有四种存档：

| 存档 | 是什么 | 存在哪 | 清缓存 / 换设备后还在吗 |
| --- | --- | --- | --- |
| 模拟器即时存档 | 模拟器引擎自带的存档槽，把这一刻整机状态冻住 | 浏览器，引擎自己的存储 | 不在。想留底就「捕捉当前进度」 |
| 模拟器原生存档 | 游戏自己的存档（电池存档 / SRAM），RPG 里在游戏菜单存的通常是它 | 浏览器，引擎自己的存储 | 不在。平台不备份它 |
| 本地存档 | 平台「存档管理」里那份：主机是即时存档的拷贝，Flash 是 `.sol` | 浏览器，平台自己的存储 | 不在（可以「下载」到磁盘留底） |
| 云端存档 | 把本地存档整包存到服务器 | 服务器，按账号 | **在**，换设备也能还原 |

前两种归模拟器引擎自己管，平台碰不到；平台能备份、能同步的只有后两种。

**为什么有的游戏存不了？** **HTML5 和大部分 Flash 游戏本身就没有「落盘存档」这个功能**，
进度放在内存里（比如魔塔这类游戏），关掉页面就没了。

**Flash 游戏要怎么存？** 得**先在游戏里存一次档**，之后在「存档管理」里点「捕捉当前进度」才能抓到
`.sol` 文件。另外**捕捉之后游戏一定会重启**，这是 Ruffle（Flash 运行时）的限制，不是出错，
重启完接着玩就行。

**换了台电脑，键位全变了？** 进游戏时会自动写回账号里的配置；改完记得点「保存配置」上传。

**找不到「显示机壳」？** 只有 GBA / FC / GBC 有机身图。

**截图截出来全黑？** 极少数浏览器拷贝画面时会拿到全黑的一帧，换一个浏览器试试。

**某盘游戏的「攻略」菜单项不见了？** 攻略是磁盘上的一个文件夹，被删掉或挪走，入口就跟着消失。

**别人看不到我的截图？** 本来就看不到——截图按账号隔离，只有本人可见可改。

## 待改进
