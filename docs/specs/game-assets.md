# 游戏素材：封面、截图与图集

## 范围与权威

- 本规格覆盖封面渲染、封面美化、游戏截图、截图相册、游戏图集与详情图片栏。
- 卡片规则权威在 `frontend/src/components/games/GameCover.vue` 与 `constants/gameCardAspect.js`。
- 美化样式、洞口几何与合成算法权威在 `constants/coverStyles.js`、`utils/coverCompose.js`。
- 截图与图集表结构见 [`../data_dict.md`](../data_dict.md) 的 `game_screenshots`、`game_gallery_images`。
- 上传校验在 `backend/games/screenshot_service.py`、`gallery_service.py`、`images.py`。

## 数据与路径

| 内容 | 相对路径 |
|---|---|
| 封面 | `game/{game_type}/{卡带ID}/cover.{后缀}` |
| 游戏图集 | `game/{game_type}/{卡带ID}/image/{uuid}.{后缀}` |
| 游戏截图 | `image/{用户名}/{game_type}/{卡带ID}/{uuid}.{后缀}` |

- 路径规则集中在 `backend/games/paths.py`；封面扩展名统一 jpg/jpeg/png/gif/webp。
- 图集与截图后缀由内容 magic 决定；支持 PNG/JPG/WebP/GIF，单张 ≤16MB。
- 截图行存 `file_path`、`size`、`mime`、`description`、`sort_order`。
- `file_path` 不下发；读图时用入库时 magic 定下的 `mime` 当 content-type。
- 截图目录里的 `game_type` 是上传当时的类型，读取与清理一律用 `file_path`。
- 图集在游戏目录内、类型不可变；图集按游戏共享，截图按账号隔离。

## 行为与规则

### 封面渲染与分组

- 封面渲染集中在 `GameCover.vue`，**只有游戏中心的卡片**用它。
- 「全部游戏」网格与「最近游玩」rail 都走 `GameCard` → `GameCover`。
- 详情图片栏、管理页缩略图与表单预览都显示封面原图，不套这一层。
- **所有游戏类型一视同仁，就是封面原图**；渲染层不按类型分支。
- 光盘与卡带的观感由「美化封面」合成进封面文件本身。
- 卡片宽就是「正方形限制框」的边长；封面等比缩放到长或宽触到框边、居中，框内用 `cqw`。
- rail 传 `CARD_ASPECT_RAIL`（`1 / 1`），卡片正方形、整行高低一致。
- 「全部游戏」不传 `aspect`，卡片高 = 封面高，同类型整行仍齐平。
- 「全部游戏」在游戏类型内**再按封面类型分子网格**，同一种封面严格同一行。
- 行顺序 = `coverTypesFor(slug)`；认不出的值兜到末尾，空的那组固定排最后。

### 封面美化

- 入口在游戏管理页编辑弹框「游戏封面」行的「美化封面」按钮。
- 组件是 `frontend/src/components/games/CoverBeautifyDialog.vue`。
- 样式由游戏类型给一组；顺序即单选顺序，第一个是默认。
- 打开时按当前 `cover_type` 默认选中；没设过就选列表第一个。
- 弹框标题右边始终有一排方框单选，走 `AppDialog` 的 `#header` 插槽。
- 只有一种样式的 `flash`、`gba`、`nds` 也出这排单选，那一项 `disabled`。
- 切换样式只重新合成，不重新下载原封面。
- 只在编辑模式且类型支持时出现；新建弹框没有；没有封面时按钮在但点不动。
- 弹出即自动合成；左原封面、右美化后，右栏铺棋盘格底。
- 确认后经 `uploadAsset(id, "cover", { file, coverType })` 覆盖原封面。
- 覆盖**不可逆**，后端会删掉原封面；样式 id 与文件在同一次调用写入 `cover_type`。
- 产物是 PNG，必须带 Alpha；`toBlob` 只出 PNG，不要传 `{ alpha: false }`。
- 素材图必须 `await` 到加载完成，否则 `drawImage` 静默不画。
- 样式分组：`flash`→DISK；`gb`→GB/GBC；`gba`→GBA；`nds`→NDS；`nes`→FC/NES。
- `h5`、`snes`、`sega*` 不支持美化，按钮不显示，`cover_type` 永远为空。
- `cover_type` 可空；集合与顺序以后端 `COVER_TYPES_BY_GAME_TYPE` 为权威。
- 前端 `coverTypesFor()` 是展示层镜像，两边 id 集合与顺序必须逐字一致。
- 只有两条写入路径：编辑弹框文字单选，与「美化封面」的同一次提交。
- 新建、网络上传、搬运一律留空；新建弹框没有这一项。
- 非法 `cover_type` 返回中文 400；类型创建后不可变，封面类型不随换本体变化。

### 卡带合成算法

- 卡带采用「先把封面缩放到洞口长宽比，再与底图合并」。
- 缩放是 `object-fit: fill`：拉伸填满、不裁切、不留边，比例不符就是变形。
- 底图是没贴过贴纸的原始卡带；NDS 贴纸窗透明，先铺 `holeFill` 底色。
- 贴之前按洞口形状 `clip()` 一刀；形状之外仍是机身像素或凹槽阴影。
- 圆角可四角相同或按角指定；斜角由 `cornerChamfers()` 给，目前没有样式在用。
- NDS 是图层顺序例外：`baseOnTop: true` 让封面先画、底图最后整张盖上来。
- NDS 顶部 logo 黑区、左右分隔线、下方黑条都在封面之上。
- 封面只从镂空窗露出；封面自带的 logo 被黑条盖住，不会出现两个 logo。
- NDS 的卡带 ID 用白色等宽字体画进下方黑条，右对齐、垂直居中、右边留白 20px。
- 「底图填色」与「封面裁切」是两件事，NES 那张最容易混淆。
- NES 洞口上边就是画布顶边，底图填色时上两角是直角；封面裁切仍是四角 r=10。

| 素材 | 整图尺寸 | 洞口矩形 | 圆角 |
|---|---|---|---|
| `gb-cart.png` | 426×500 | (53,151) 322×287 | 8 |
| `gbc-cart.png` | 438×503 | (58,163) 322×287 | 8 |
| `gba-cart.png` | 640×370 | (88,86) 464×235 | 12 |
| `nds-cart.png` | 487×520 | 标签区 (51,35) 395×374 | 直角 |
| `fc-cart.png` | 700×460 | (56,54) 592×290 | 10 |
| `nes-cart.png` | 700×779 | (283,0) 323×527 | 10 |

- 底图文件名一律 `<样式 id>-cart.png`；换素材必须同步改尺寸、洞口与圆角。
- 要贴同一张画的多个样式，洞口尺寸必须做成一样。
- 底图按 `sx = 目标洞口宽 / 原洞口宽`、`sy = 目标洞口高 / 原洞口高` 重采样，
  再按整数坐标重填一遍洞口。
- 本来就贴不同画的样式各按自己的素材来：FC 2.04:1，NES 0.61:1。
- 没有现成底图时，用 `.claude/skills/cartridge-clear-scene` 清掉贴纸窗并补机身色。

### 光盘合成算法

- Flash 光盘是程序化绘制，没有底图；输出画布 1024×1024。
- 盘直径占 84%，四周留透明；整盘先做一次性圆形 `clip()`。
- 图层顺序：盘面底色 → 封面 → 盘心 Flash 标志 → 三层反光。
- 盘面底色是 135deg 线性渐变；封面按居中 `min(宽,高)` 正方形画进盘面。
- 盘心标志 `flash-logo.png` 的边长占**盘直径**的 15%。
- 三层反光由底到顶：118deg 斜向高光、外圈暗调与塑料边、盘心积层环。
- 顺序反了上面那层会把下面的盖掉。
- 外圈与盘心两个径向渐变的百分比基准是**盘半径**，不是盘直径。
- 渐变端点按方向向量 `(sinθ, −cosθ)` 与长度 `|W·sinθ| + |H·cosθ|` 自算。
- 不要把 `(0,0)→(W,H)` 当端点；那只在 45° 整数倍上碰巧对。

### 游戏截图

- 截图入口在主机播放页标题栏「截图」按钮或 `Ctrl+Shift+S`。
- 宿主页优先取引擎自带截图（内核侧读帧缓冲，得到原生像素）；拿不到或全黑时
  退回同一帧 `requestAnimationFrame` 里拷画布。
- 引擎 WebGL 上下文是 `preserveDrawingBuffer: false`；个别浏览器会拷到全黑。
- 两条都黑时按原生帧返回，不报错；返回宽高是 PNG 真实像素尺寸。
- 截下后**不下载**，先弹 `ScreenshotConfirmDialog.vue` 确认框。
- 预览框宽固定 180px、高度按截图真实比例（横图封顶 180 方框）；NDS 竖版会变高。
- 描述是单行输入，`maxlength=15`，没有计数行；描述框自动获得焦点。
- 按回车或点「确认」才带描述上传进截图图库。
- 取消、ESC 或关闭就整张丢掉，预览 objectURL 在关闭与卸载时释放。
- 上传成功提示「截图已存入图库（宽 × 高）」；「上传图片」可传本地图片作第二来源。
- 截图按账号隔离，越权与不存在一律 404。

### 截图相册管理

- 详情信息区右栏「截图 [管理]」打开 `ScreenshotManagerDialog.vue`。
- 它把接口注入 `ImageAlbumDialog.vue`；图集管理复用同一个相册组件。
- 相册式平铺视图：上面图片、下面描述；自适应列宽。
- 一进来就是管理界面，没有「还没有截图」这类空态文案。
- 左上角恒有「上传图片」，`accept` 只收 png/jpeg/webp/gif。
- 单击描述就地改：换成同宽、同高、同字号的单行 `input`。
- 没有取消/保存按钮与字数计数；回车或失焦存下，ESC 放弃，没改动不发请求。
- 同一时刻只有一张处于编辑态；选择模式下点描述算勾选。
- 删除入口是工具条右上角固定的「删除」。
- 第一下进删除模式（「已选 N 张」+ 取消），点整块切换勾选。
- 再点一次「删除 N 张」才真删；这一步就是确认，不再弹确认框。
- 删除逐张调接口；中途失败也统一重拉对齐，完成后通知父组件刷新。
- 网格 `overflow-y: auto` + `scrollbar-gutter: stable`，滚动条不影响列宽。
- 整块 `draggable`；选择模式与描述编辑中禁用拖动，`img` 上 `draggable="false"`。
- 拖动用原生 HTML5 DnD；`dragstart` 必须 `setData`，否则 Firefox 不启动拖拽。
- `drop` 先按同一语义本地 `splice`，再调 `move`，用返回的整份列表覆盖。
- 后端分数排序：新图取「最大分 + 1000」追加；拖动只改被拖那行，取相邻中值。
- 相邻间隔 ≤ `1e-3` 时，后端才把整份按步长重新铺开。
- 任何变更成功后都通知详情弹框重拉，避免图片栏数据陈旧。

### 详情图片栏

- 图片栏是 `GameScreenshotGallery.vue`，纯展示 + 内部翻页状态。
- 一行 4 个 180px 限制框，格间距 14px，总宽 762px；框内 `contain`，不裁不拉。
- 封面、图集保持 1:1；截图按机种比例，NDS 是竖版。
- NDS 固定按 dual 的 256:438 展示；top/side 截图在框内 `contain`，是已知限制。
- 截图框不加底色、不做圆角；图片栏与信息区之间没有分隔线。
- 封面恒占第一格；没有封面也留空占位，不把位置让给截图。
- 其后的顺序是共享图集、本人的截图。
- 每格下方一行定高 18px 的描述，水平居中；封面格留空但同样占位。
- 格子排在一条 flex 轨道上，翻页是 `translateX(-page × 776px)` 的水平滑动。
- 776 = 4 格宽 + 4 道缝；0.3s ease；`PAGE_OFFSET` 必须与样式一致。
- 离屏格子带 `loading="lazy"`；只有一页不出按钮，到边界禁用。
- 左右按钮压在图片栏边缘；滚轮上滚前翻、下滚后翻，真能翻时才 `preventDefault`。
- 第 1 页 = 封面 + 3 张图；第 2 页起每页 4 张，不再有封面。
- 图增删后页码收敛回最后一页；什么都没有时整条图片栏不渲染。
- 单击图片可看大图；大图里左右方向键翻页，ESC 退回。

### 游戏图集

- 图集是一盘游戏一套的展示图，如宣传图、说明书扫描件。
- 图集按游戏**共享**：任何登录用户都能看、能传、能改描述、能删、能排序。
- 管理入口在游戏管理页编辑弹框的「图集 → 管理」；新建弹框没有，详情图片栏只读。
- 图集与截图共用同一套相册实现，只少了「用户」这一维。
- 上传校验与截图相同：非空、单张 ≤16MB、按 magic 认格式、描述 ≤15 字。
- 图集落在游戏目录内，改卡带 ID 时随游戏目录一起搬并改写 `file_path`。
- 删游戏时图集行与文件一并清掉。

## 边界与错误

- 上传图片为空、超过 16MB、或 magic 认不出格式，均返回中文 400。
- 描述超过 15 字返回中文 400，不静默截断。
- 游戏不存在时上传截图或图集返回 404。
- 拖动落点 `to_index < 0` 或 ≥ 当前列表长度返回 400「目标位置不合法。」。
- 看、改、删别人的截图一律 404；图集没有归属限制，任何登录用户都能改。
- 非法 `cover_type` 返回 400；`kind="game"` 时忽略；不支持的类型永远为空。
- 美化封面会删除原封面文件，不可撤销。
- 截图确认框取消后整张丢弃，不上传、不下载。
- 删游戏时截图行/文件/目录与图集行一并清掉；目录按 `file_path` 反推。
