# 游戏榜单的 CSV

这里是「游戏发现 → 游戏榜单」的数据源：**每个机种一个 CSV，文件名就是机种 id**，
五列 `序号,中文名,英文名,评分,卡带ID`，UTF-8（带 BOM）、CRLF。

- **只被建索引读**（`backend/games/search_index.py`，两个入口：服务启动时的自动补建/就地补载与
  `make index`）。代码不 `import` 这个目录，运行期的榜单接口只读构建好的 `<数据根>/db/game.db`。
- 这个目录**随 `backend/` 一起进 api 镜像与 Windows 包**，所以宿主机上的 `make index` 与
  容器/包里的启动加载都能用到它。
- 目录里只放数据：不要加 `.py`（没有 `__init__.py` 时 Python 会把它当 namespace package）。
- 它**不能**放进旁边的 `../catalog/`：那个目录会被整目录扫成检索索引，五列的榜单会被当成坏行。
- 文件名 stem 必须在 `backend/games/platforms.py` 的 `PLATFORM_BY_ID` 里，也就是
  EmulatorJS 的 system key：`nes.csv`、`snes.csv`、`segaMD.csv`、`psx.csv`…
  当前覆盖 34 个可玩机种；`tests/test_platforms.py` 会检查文件集合与可玩机种完全一致。

## 格式

| 列 | 规则 |
|----|------|
| 序号 | 正整数；同一文件内不得重复；允许缺号 |
| 中文名 | 可空；查不到译名就留空，页面显示 `—` |
| 英文名 | 非空；保留榜单原标题（去掉地区/修订/语言标注） |
| 评分 | 非空；普通十进制数字（如 `8.84316671219157`）；落库为 double |
| 卡带ID | 每行 0~2 个；可为空；与库存比对 |

- **序号**：该机种内的评分名次；页面按评分降序展示，同分按序号稳定排序。
- **机种**：由文件名决定，不写进行里。加/删机种就是加/删文件。
  页面下拉显示词表里的统一中文名（`任天堂 GBA`、`世嘉 MD`…）；页面默认不选类型，看全部机种。
- **中文名**：
  - 从旧版 `ranking.csv`（已删除，可在 git 历史中找到）按「机种 + 英文名」回填；
    匹配时忽略大小写、空白与常见标点，`&` 与 `and` 视为相同。
  - 回填只填空值，不覆盖已有内容。
  - 查不到就留空；页面中文名单元格显示 `—`，英文名照常可点。
- **英文名**：
  - 保留榜单原标题；只去掉地区/修订/语言标注。
  - 像 `Medarot Perfect Edition (Kabuto Version)` 这种区分版本的括号属于标题本身，保留。
- **评分**：
  - MobyGames 的 Moby Score 原始 double，不四舍五入写入。
  - 页面固定显示两位小数，四舍五入（`8.487593…` → `8.49`）。
- **卡带ID**：
  - 多个之间用 `;` 分隔，也接受 `、` `,` `，` `/` `；`。
  - 空格、连字符、下划线不是分隔符（卡带 ID 里常有空格，如 `POKEMON FIRE RED`）。
  - 可以为空（查不到编号就留空，整列省略也行）；超过 2 个会被拒绝。
  - 这一列会与平台库存的卡带 ID 比对（比对时去首尾空白、转大写）。
  - 对上的行在榜单页上中英文名会变成可点击链接，点了直接进播放页。
  - 想看到链接，编号就要照游戏管理页里填的卡带 ID 写。
  - 像 `Part No. 7004 0894` 这种带空格或点的原文永远匹配不上。
  - 卡带 ID 按**美版、日版、其他地区**的顺序写，最多 2 个；有美版就写美版、第二位写日版；
    两者都没有才放其他地区的编号。编号照卡带标签抄（FC 是 `NES-XX-USA` / `HVC-XX` / `KON-RCxxx`
    这类，GB/GBC/GBA 是 `DMG-…` / `CGB-…` / `AGB-…`；**早期 GB 的日版编号形如 `DMG-XXA`**，
    例如 `DMG-TRA`、`DMG-MLA`）。**查不到就留空，不要拿美版编号硬推日版。**
- 表头可选：第一条非空行第一格是 `序号`（或 `排名`）时跳过。旧版带 `机种名称` 第二列的表头
  会被明确拒绝，请改成现在的五列。
- 字段内的逗号必须用双引号包起来，例如 `3,"某游戏, 特别版",Some Game,8.5,ID1`。
- 卡带 ID 为空时第 5 列可以留空、也可以整个省掉（`4,某游戏,Some Game,8.5` 等价于
  `4,某游戏,Some Game,8.5,`）。
- 空行跳过；Excel 常见的行尾多余空列会被裁掉。
- **只有表头的文件合法**（例如暂无评分的 `c128.csv`、`pcfx.csv`、`pet.csv`），加载时跳过；
  所有文件都没有数据行才算错误。
- 格式错误会让 `make index` 直接失败并指出**文件名与行号**；服务启动时加载失败只记一条 warning，
  不影响检索与启动。

## 示例

```csv
序号,中文名,英文名,评分,卡带ID
1,精灵宝可梦 火红,Pokémon FireRed,8.345679012345679,POKEMON FIRE RED
2,黄金太阳,Golden Sun,8.1,GSAE
3,双版本示例,Double Version Example,7.75,ID1;ID2
4,查不到编号的游戏,No ID Game,7,
5,,没有中文名的游戏,6.5,
```

## 数据从哪来

- `tools/mobygames/mobygames-ranking.user.js` 按机种抓取 MobyGames 排行，直接写成上述五列，
  中文名与卡带 ID 留空。
- 中文名与卡带 ID 由人工整理流程回填；本仓库当前的数据来自旧版 `ranking.csv` 的按名匹配。
- **重新跑抓取脚本会覆盖已有中文名与卡带 ID**（脚本只写空列），重抓后需要重新回填。

## 生效方式

- 手动：在项目根目录跑 `make index`（会连检索索引一起重建，约 1–2 秒）。
- 自动：服务启动时发现 `game.db` 里的榜单指纹或表结构版本与这个目录不一致（或还没加载过），
  会就地补一次；源文件没变时一个字节都不写。
  - 指纹覆盖目录里所有 CSV 的「文件名 + 原始字节」，改名、换内容、增删文件都会触发重载。
- 只重建检索、暂时不碰榜单：`python -m backend.cli index --skip-ranking`。
- 临时换一份榜单目录：`python -m backend.cli index --ranking-dir PATH`。
- 索引构建、只读连接与库存关联细节见
  [`docs/modules/game-discover.md`](../../../docs/modules/game-discover.md)。
