# 游戏榜单的 CSV

这里的 `ranking.csv` 是「游戏发现 → 游戏榜单」的数据源：**4 列、无表头（或带一行表头）**、
`序号,机种名称,游戏名称,游戏卡带ID`，UTF-8（可带 BOM）、CRLF 或 LF 均可。

- **只被建索引读**（`backend/games/search_index.py`，两个入口：服务启动时的自动补建/就地补载与
  `make index`）。代码不 `import` 这个目录，运行期的榜单接口只读构建好的 `<数据根>/db/game.db`。
- 这个目录**随 `backend/` 一起进 api 镜像与 Windows 包**，所以宿主机上的 `make index` 与
  容器/包里的启动加载都能用到它。
- 目录里只放数据：不要加 `.py`（没有 `__init__.py` 时 Python 会把它当 namespace package）。
- 它**不能**放进旁边的 `../csv/`：那个目录会被整目录扫成检索索引，四列的榜单会被当成坏行。

## 格式

| 列 | 规则 |
|----|------|
| 序号 | 正整数；同一机种内不得重复；允许缺号 |
| 机种名称 | 非空；会被归一成统一机种 |
| 游戏名称 | 非空；原样展示 |
| 游戏卡带ID | 每行 0~2 个；可为空；与库存比对 |

- **序号**：页面按它排序并原样展示。
- **机种名称**会被解析成统一机种：词表在 `backend/games/platforms.py`，
  机种 id 就是 EmulatorJS 的 system key。
  - `GBA` 与 `gba`、`MD` 与 `世嘉MD` 都算同一个机种。
  - 「同一机种内序号唯一」按归一后的机种判。
  - 建议写大写短名（`GBA`、`GB`、`GBC`、`FC`、`SFC`、`MD`…）。
  - 页面下拉显示词表里的统一中文名（`任天堂 GBA`、`世嘉 MD`…），默认选中 `FC`。
- **游戏卡带ID**：
  - 多个之间用 `;` 分隔，也接受 `、` `,` `，` `/` `；`。
  - 空格、连字符、下划线不是分隔符（卡带 ID 里常有空格，如 `POKEMON FIRE RED`）。
  - 可以为空（查不到编号就留空，整列省略也行）；超过 2 个会被拒绝。
  - 这一列会与平台库存的卡带 ID 比对（比对时去首尾空白、转大写）。
  - 对上的行在榜单页上游戏名会变成可点击链接，点了直接进播放页。
  - 想看到链接，编号就要照游戏管理页里填的卡带 ID 写。
  - 像 `Part No. 7004 0894` 这种带空格或点的原文永远匹配不上。

- 卡带 ID 按**美版、日版、其他地区**的顺序写，最多 2 个：有美版就写美版、第二位写日版；
  两者都没有才放其他地区的编号。编号照卡带标签抄（FC 是 `NES-XX-USA` / `HVC-XX` / `KON-RCxxx`
  这类，GB/GBC/GBA 是 `DMG-…` / `CGB-…` / `AGB-…`；**早期 GB 的日版编号形如 `DMG-XXA`**，
  例如 `DMG-TRA`、`DMG-MLA`）。**查不到就留空，不要拿美版编号硬推日版。**
- 表头可选：第一条非空行第一格是 `序号`（或 `排名`）时跳过。
- 字段内的逗号必须用双引号包起来，例如 `3,GBA,"某游戏,特别版",ID1`。
- 卡带 ID 为空时第 4 列可以留空、也可以整个省掉（`4,GBA,某游戏` 等价于 `4,GBA,某游戏,`）。
- 空行跳过；Excel 常见的行尾多余空列会被裁掉；空文件、只有表头都算错误。
- 格式错误会让 `make index` 直接失败并指出**文件名与行号**；服务启动时加载失败只记一条 warning，
  不影响检索与启动。

## 示例

```csv
序号,机种名称,游戏名称,游戏卡带ID
1,GBA,精灵宝可梦 火红,POKEMON FIRE RED
2,GBA,黄金太阳,GSAE
3,GBA,某双版本游戏,ID1;ID2
4,GBA,查不到编号的游戏,
```

## 生效方式

- 手动：在项目根目录跑 `make index`（会连检索索引一起重建，约 1 秒）。
- **换了机种写法**（写了词表里还没有的名字）要去 `backend/games/platforms.py` 补一条别名，
  否则它会被归为「未收录」、下拉里以原文出现；`tests/test_platforms.py` 会拿这份数据提醒你。
- 自动：服务启动时发现 `game.db` 里的榜单指纹与这份 CSV 不一致（或还没加载过），会就地补一次；
  源文件没变时一个字节都不写。
- 只重建检索、暂时不碰榜单：`python -m backend.cli index --skip-ranking`。
- 索引构建、只读连接与库存关联细节见
  [`docs/specs/game-discover.md`](../../../docs/specs/game-discover.md)。
