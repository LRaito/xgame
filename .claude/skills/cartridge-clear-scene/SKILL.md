# cartridge-clear-scene：把卡带图上的封面清掉并补色

拿一张**贴纸窗里印着封面**的卡带成品图，把那一整块——封面图案、左右两条白色分界栏，
以及贴纸自己那圈抗锯齿/阴影过渡边——清掉，四角按圆角填上**机身色**，输出一张
**看起来还没贴过贴纸的原始卡带**。卡带轮廓、机身明暗、缺口透明都不动。

补色**默认取窗外那圈机身色**；窗外不是机身时（透明壳的卡带，窗外透出来的是下层电路板）
用 `--color` 手工指定。

本技能在**本项目**里用来做「美化封面」的卡带底图（`frontend/public/*-cart.png`）：
产出的底图交给 `frontend/src/constants/coverStyles.js` 的 `CART_STYLES`，
**脚本打印的最后那行几何就是该填进去的 `image` / `hole` / `radius`**。

## 用法

```bash
python3 .claude/skills/cartridge-clear-scene/clear_scene.py <源图> [-o 输出目录] \
        [--rect x,y,w,h] [--radius N] [--pad N] [--color R,G,B] [--check]
```

- `<源图>`：必填，Pillow 能读的格式（png/jpg/webp…）。**别原地覆盖源图**，脚本只写新文件。
- `-o/--out-dir`：默认与源图同目录。
- `--rect x,y,w,h`：手工指定要清的矩形（源图坐标），给了就不自动检测（贴纸是灰度图案、
  或窗口不是矩形时用）。
- `--radius`：洞口圆角半径，默认 8 —— 与 `coverStyles.js` 里卡带洞口的 `radius` 保持一致；
  拉伸过的底图要跟着重算（见下面「和别的样式对齐」）。
- `--pad`：自动检测出的窗口向外扩这么多像素再填，默认 2。
- `--color R,G,B`：补色，不给就自动取窗外那圈机身色。**窗外不是机身时必须给**
  （透明壳卡带窗外透出来的是电路板颜色，直接取会补出一块绿）。
- `--check`：额外出一张棋盘底合成图，并在上面描出窗口矩形，肉眼验洞口。

输出（按源文件名 `<名字>`）：`<名字>_blank.png`（补好色的原始卡带）。`--check` 时另有
`<名字>_blank_check.png`。

屏幕上会打印贴纸图案的 bbox、四条边各自的取值与范围、补色的矩形与颜色、以及那行现成的
`coverStyles.js` 几何。**四条边的「范围」不是 0 就要停下来看**，见最后一节。


## 算法（改脚本前先读这段）

1. **找种子框**：用 HSV 饱和度阈值挑出贴纸上的**彩色图案**，取它的 bbox。
   （贴纸白边的亮、机身灰的暗都够不到这个阈值，只有图案够得到。）
2. **左右边**：从种子框中段那几行，各自贴着图案边界**往外走**，一直走到机身为止。
   判据是「够亮 **或** 有彩色」= 还是贴纸。
3. **上下边**：在**左边栏内部**那几列上向上/向下走同样的判据。
   白边是通高的，拿它的列比拿图案的行稳（图案的上下沿参差不齐）。
4. **往外走要「看远一点」**：不能一碰到「不是贴纸」就停——白边上的黑色文字、贴纸边的阴影
   都只有几像素宽（有的卡带图，右侧那排竖排警告语几乎横跨整个窗口高度，一停就把窗口边
   留在半路）。所以判据是：**往后 `LOOKAHEAD` 个像素里一个贴纸像素都没有，才算真走出去了**。
   宁可多啃几像素机身（看不出来），也不能把贴纸留在底图上（一眼就看出来）。
5. **四条边取中位数**，各往外扩 `--pad` 像素（贴纸自己的过渡边要一起清掉，否则补色块边上
   留一圈半白的细边），按 `--radius` 圆角矩形**填成机身色**（不透明）。补色默认取窗外
   `PROBE_STEPS` 那几圈机身像素的中位数（让开一段距离是为了避开贴纸凹槽那圈阴影），
   `--color` 可以覆盖。

脚本顶部的常量就是全部旋钮，按症状挑：

| 常量 | 什么时候动它 |
|------|--------------|
| `SAT` | 贴纸图案很淡（浅色/低饱和）时报「找不到彩色贴纸图案」，往小调 |
| `SEED_MIN` | 图案里有零星的彩色噪点，会在奇怪的地方造出种子框，往大调 |
| `BRIGHT` | 白边与机身的分界：机身偏亮就往大调，白边偏暗就往小调 |
| `LOOKAHEAD` | 边上那道暗色窄条比它还宽，走出去时被卡住（四条边的「范围」很大）——往大调 |
| `MAX_GAP` | 从种子框往外最多走多远，防止判据失灵时一路啃进机身 |
| `PAD` | 补完色块边上还留一圈细边（过渡边没清干净）就往大调 |
| `PROBE_STEPS` | 自动取的机身色偏暗（踩到贴纸凹槽的阴影了）就往大调；窗外本来就窄就调小 |
| `OPAQUE` | 窗外那圈有半透明像素被算进取样、补色发灰，就往大调 |

## 和别的样式对齐（这一步**不属于本技能**）

同一个游戏类型里有多个卡带样式、且它们本来就该贴同一张画时，同一张封面贴进哪个样式的
洞口，占的区域必须一样大。做法是：**先按本技能清好**，再按
`sx = 目标洞口宽 / 补色矩形宽`、`sy = 目标洞口高 / 补色矩形高`**整图重采样**
（这一步不写进技能：目标是哪张图、哪个洞口，只有具体那一次才知道）。
重采样会把补色块的边糊掉，所以之后**再按整数坐标把窗口重填一遍**，补色块才是硬边、
尺寸分毫不差；`radius` 也要跟着定（比拉伸后的圆角略小一点，圆角外就还是机身像素）。

## 换图后清不干净时

- **打印里某条边「范围」很大**（比如右栏的警告语把右边卡住了）：先调 `LOOKAHEAD`。
- **补色块边上框着一圈半白的细边**：`PAD` 调大。
- **圆角外多啃了一块机身**：`radius` 调小（填的弧要落在贴纸的圆弧之外一点点，
  半径取「贴纸自己的圆角 + PAD」上下）。
- **补色块里还看得见贴纸像素**：某条边检测短了，看 `--check` 的洋红描边压没压住贴纸边，
  配合 `LOOKAHEAD` / `BRIGHT` 调。
- **补色跟窗外机身明显不是一个色**：窗外不是机身（透明壳），用 `--color R,G,B` 手工给。
- **报「找不到彩色贴纸图案」**：贴纸是灰度图，用 `--rect x,y,w,h` 直接给窗口。
