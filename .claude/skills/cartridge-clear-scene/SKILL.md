# cartridge-clear-scene：把卡带图上的封面清掉并补色

拿一张**贴纸窗里印着封面**的卡带成品图，清掉整块：

- 封面图案。
- 左右两条白色分界栏。
- 贴纸自己那圈抗锯齿 / 阴影过渡边。

四角按圆角填上**机身色**，输出一张看起来还没贴过贴纸的原始卡带。
卡带轮廓、机身明暗、缺口透明都不动。

补色默认取窗外那圈机身色。
窗外不是机身时（透明壳卡带，窗外透出下层电路板），用 `--color` 手工指定。

本技能在项目中用来做「美化封面」的卡带底图：

- 底图位置：`frontend/src/assets/carts/*-cart.png`。
- 底图交给 `frontend/src/constants/coverStyles.js` 的 `CART_STYLES`。
- 脚本打印的最后一行几何，就是该填进去的 `image` / `hole` / `radius`。
- 底图放 `src/assets/`，由 Vite 加内容哈希，换图后 URL 自动变。
- 别放 `public/`：文件名固定，nginx 不带 Cache-Control，会被浏览器启发式缓存顶住。
- 素材几何与多样式对齐规则见
  [`docs/specs/game-assets.md`](../../../docs/specs/game-assets.md)。

## 用法

```bash
python3 .claude/skills/cartridge-clear-scene/clear_scene.py <源图> \
        [-o 输出目录] [--rect x,y,w,h] [--radius N] \
        [--pad N] [--color R,G,B] [--check]
```

- `<源图>`：必填，Pillow 能读的格式。
  **别原地覆盖源图**，脚本只写新文件。
- `-o/--out-dir`：默认与源图同目录。
- `--rect x,y,w,h`：手工指定要清的矩形（源图坐标）。
  - 给了就不自动检测。
  - 贴纸是灰度图案、或窗口不是矩形时用。
- `--radius`：洞口圆角半径，默认 8。
  - 与 `coverStyles.js` 里卡带洞口的 `radius` 保持一致。
  - 拉伸过的底图要跟着重算。
  - 也可写成 `tl,tr,br,bl` 按角给。
  - 洞口上边顶到画布顶边时，上面两角要给 0。
- `--pad`：自动检测出的窗口向外扩多少像素再填，默认 2。
- `--color R,G,B`：补色。
  - 不给就自动取窗外那圈机身色。
  - 窗外不是机身时必须给。
- `--check`：额外出一张棋盘底合成图，并描出窗口矩形。

输出（按源文件名 `<名字>`）：

- `<名字>_blank.png`：补好色的原始卡带。
- `<名字>_blank_check.png`：仅 `--check` 时出。

屏幕上会打印：

- 贴纸图案的 bbox。
- 四条边各自的取值与范围。
- 补色的矩形与颜色。
- 现成的 `coverStyles.js` 几何。

四条边的「范围」不是 0 就要停下来看，见最后一节。

## 依赖

只用 **Pillow**，不在 `requirements.txt` 里（后端运行不需要）。

```bash
pip install Pillow
```

## 算法（改脚本前先读这段）

1. **找种子框。**
   - 用 HSV 饱和度阈值挑出贴纸上的彩色图案，取它的 bbox。
   - 贴纸白边的亮、机身灰的暗都够不到阈值，只有图案够得到。
2. **左右边。**
   - 从种子框中段那几行，贴着图案边界往外走，一直走到机身为止。
   - 判据是「够亮 **或** 有彩色」= 还是贴纸。
3. **上下边。**
   - 在左边栏内部那几列上向上/向下走同样的判据。
   - 白边是通高的，拿它的列比拿图案的行稳。
4. **往外走要看远一点。**
   - 不能一碰到「不是贴纸」就停。
   - 白边上的黑色文字、贴纸边的阴影都只有几像素宽。
   - 判据：往后 `LOOKAHEAD` 个像素里一个贴纸像素都没有，才算真走出去。
   - 宁可多啃几像素机身，也不能把贴纸留在底图上。
5. **四条边取中位数。**
   - 各往外扩 `--pad` 像素。
   - 按 `--radius` 圆角矩形填成机身色（不透明）。
   - 补色默认取窗外 `PROBE_STEPS` 那几圈机身像素的中位数。
   - `--color` 可以覆盖。

脚本顶部的常量就是全部旋钮：

| 常量 | 什么时候动它 |
|---|---|
| `SAT` | 贴纸图案很淡时报找不到图案，往小调 |
| `SEED_MIN` | 图案里有零星彩色噪点，往大调 |
| `BRIGHT` | 白边与机身的分界：机身偏亮调大，白边偏暗调小 |
| `LOOKAHEAD` | 边上暗色窄条太宽，走出去被卡住，往大调 |
| `MAX_GAP` | 从种子框往外最多走多远 |
| `PAD` | 补色块边上留细边，往大调 |
| `PROBE_STEPS` | 自动取的机身色偏暗，往大调；窗外窄则调小 |
| `OPAQUE` | 窗外半透明像素让补色发灰，往大调 |

## 换图后清不干净时

- **某条边「范围」很大**：先调 `LOOKAHEAD`。
- **补色块边上有半白细边**：`PAD` 调大。
- **圆角外多啃了机身**：`radius` 调小。
- **补色块里还看得见贴纸像素**：看 `--check` 的洋红描边，
  配合 `LOOKAHEAD` / `BRIGHT` 调。
- **补色与窗外机身明显不同**：窗外不是机身，用 `--color` 手工给。
- **报「找不到彩色贴纸图案」**：贴纸是灰度图，用 `--rect` 直接给窗口。
