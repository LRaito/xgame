# cutout：去除封面四周杂色黑边

把深色背景上的封面主体抠出来，输出透明底 PNG，并额外给一张裁掉四周留白的版本。

- 原有倾斜角度保留（不摆正、不重采样）。
- 封面图案本身的深色区域不会被误抠。

本技能在项目中用来处理要上传成游戏封面的图：

- 管理页添加/编辑弹框的封面预览。
- 游戏中心卡片。
- 两边都吃透明 PNG。
- 封面渲染与素材规则见
  [`docs/specs/game-assets.md`](../../../docs/specs/game-assets.md)。

## 用法

```bash
python3 .claude/skills/cutout/cutout.py <源图> [-o 输出目录] [--check]
```

- `<源图>`：必填，Pillow 能读的格式。
- `-o/--out-dir`：默认与源图同目录。
- `--check`：额外在品红底 / 白底上各出一张半尺寸检查图，
  外加一张画出四条切边的图（平时不用加）。

输出（按源文件名 `<名字>`）：

| 文件 | 内容 |
|---|---|
| `<名字>_transparent.png` | 透明底、原尺寸、位置不动 |
| `<名字>_transparent_cropped.png` | 上面那张裁掉四周透明区域；通常用这张 |
| `<名字>_check_magenta.png` / `_check_white.png` | 仅 `--check` 时出，验边用 |
| `<名字>_check_edges.png` | 仅 `--check` 时出，洋红四边形画在原图上 |

屏幕上会打印：

- 全画面背景色。
- 四条边各自采到多少点、拟合上多少点。
- 四角坐标与修正的像素数。

某条边「采样多、内点少」，就说明那条边没找对。

## 依赖

只用 **Pillow**，不在 `requirements.txt` 里（后端运行不需要）。

```bash
pip install Pillow
```

## 算法（改脚本前先读这段）

1. **定位四条边。**
   - 逐行/逐列从外往内扫，找第一个「碰到封面本体」的位置。
   - 参考色：这条扫描线最外侧 `REF_PX` 个像素的中位数，
     再沿这条边做中位数平滑（`SMOOTH_W`）。
   - 判据：向后开一个 `WIN` 宽的窗口，
     窗口内「与参考色的最大通道差」的中位数超过 `TOL` 就算碰到本体。
   - 取中位数而不是单像素阈值：JPEG 噪点判不动，
     暗色封面压在同样暗的背景上时那点色差也认得出来。
   - 外侧已经不是背景色的扫描线，按「边就在画面边缘」计入，
     即 0 留白：宁可多留几像素背景，也不要把封面切掉一块。
2. **RANSAC 拟合四条边。**
   - 封面图案里的暗部边界、反光会给出乱点。
   - 取斜率中位数的稳健拟合会被带偏，所以找「内点最多的那条线」，
     再用内点最小二乘精修。
3. **只认这四条直线边。**
   - 四边围成的四边形内部强制不透明，外面一律透明。
   - 不做颜色泛洪：封面图案里与背景同色的暗部会漏出去，
     暗部换背景的圆角处又会多啃一块。
   - 封面自己的圆角照原样留着，四个角上会剩一丁点背景。
4. **按亮度反推覆盖率消黑边。**
   - 边缘带里用「内侧封面本色的模糊均值」还原颜色。
   - 用 `(像素亮度 - 背景亮度) / (本色亮度 - 背景亮度)` 当 alpha。
   - 只对「比背景亮」的过渡像素算。
   - 比背景还暗的像素是封面自己的暗部，照原样留着。

## 换图后抠不干净时

先看 `--check` 出的 `_check_edges.png`：

- 切边没压在封面轮廓上：找边的问题。
- 切边对了但边上还留杂色：第 3/4 步的问题。

脚本顶部的常量就是全部旋钮：

| 常量 | 什么时候动它 |
|---|---|
| `LIMIT` | 背景留白比它宽、边找不到，往大调 |
| `TOL` | 判据过敏切进封面就调大；暗封面暗背景判不出就调小 |
| `WIN` | 背景噪点大就调大 |
| `SMOOTH_W` | 背景明暗渐变跟不住就调大 |
| `REF_PX` | 封面顶到画面边缘的那段很窄时调小 |
| `BG_TOL` / `BG_HARD` | 判定「外侧还是不是背景、要不要按 0 留白」的松紧 |

切边是四条直线。某条边有几像素参差，只能是拟合被乱点带偏了：

- 看打印的「采样 N 点，内点 M 点」。
- M 远小于 N 就是这条边没找准。
- 别去动第 3/4 步。
